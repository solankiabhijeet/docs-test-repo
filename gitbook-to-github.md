# Gitbook to Github and Github to Gitbook

GitBook allows you to synchronize your content with **GitHub** or **GitLab** to keep your documentation and codebase in sync.

## GitHub: How it works

1. **Install App:** Add the GitBook App to your GitHub account or organization.
2. **Link Space:** Connect your GitBook space to a specific GitHub repository.
3. **Select Branch:** Choose the branch you want to track.
4. **Sync:** GitBook edits are pushed as commits; GitHub commits are pulled into GitBook history.

[Full GitHub sync instructions](enabling-github-sync.md)

## GitLab: How it works

1. **API Token:** Generate a GitLab API token and add it to your GitBook space.
2. **Link Space:** Connect your GitBook space to a GitLab repository.
3. **Select Branch:** Choose the target branch for synchronization.
4. **Sync:** Changes flow bi-directionally between GitLab and GitBook as commits.

[Full GitLab setup instructions](enabling-gitlab-sync.md)
